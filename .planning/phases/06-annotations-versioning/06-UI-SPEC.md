## Component Inventory

### 1. Annotation Toggle (Substitution)

Renders inline on an annotated ingredient or step. Allows toggling a substitution on/off.

**Structure:**
```
┌─────────────────────────────────────────────────┐
│ [toggle] Original text → Substitution text       │
│          — contributor name                      │
└─────────────────────────────────────────────────┘
```

**Visual specs:**
- Toggle switch: 36px wide × 20px tall, 20px circular thumb, 2px inset
- Track color off: `var(--ann-toggle-track)` | on: `var(--ann-toggle-track-active)`
- Thumb color: `var(--ann-toggle-thumb)`, slides left↔right with 150ms ease transition
- Original text: `text-lg`, when substitution active → `line-through`, `text-gray-400`
- Substitution text: `text-base`, `var(--ann-substitution-bg)` background, 2px left border `var(--ann-substitution-border)`, 8px left padding
- Contributor: `text-sm`, `var(--theme-text-secondary)`, preceded by em dash
- Min touch target: 44px × 44px on the toggle (padding extends hit area)
- Toggle is a `<button role="switch" aria-checked="true|false">` for accessibility

**States:**
- **Off (default):** Original text displayed normally. Toggle track is `--ann-toggle-track`. Substitution text hidden.
- **On:** Original text shown with line-through + muted color. Substitution text appears below/inline. Toggle track is `--ann-toggle-track-active`.
- **Focus-visible:** 2px outline `var(--theme-accent)`, 2px offset on toggle button.

### 2. Tip Annotation

Renders as an expandable callout below an annotated ingredient or step.

**Structure:**
```
┌─────────────────────────────────────────────────┐
│ 💡 Tip                                    [▾/▴] │
│ ┌─────────────────────────────────────────────┐ │
│ │ Tip text here                               │ │
│ │ — contributor name                          │ │
│ └─────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────┘
```

**Visual specs:**
- Trigger row: `text-sm`, `font-bold`, `var(--theme-text-secondary)`, 💡 emoji prefix
- Trigger is a `<button>` with `aria-expanded="true|false"`, min touch target 44px
- Disclosure chevron: `▾` (collapsed) / `▴` (expanded), right-aligned
- Tip body: `text-base`, `var(--ann-tip-bg)` background, 2px left border `var(--ann-tip-border)`, 8px padding all sides, 8px top margin
- Contributor: `text-sm`, `var(--theme-text-secondary)`, preceded by em dash
- Corner radius: `var(--radius-lg)` (8px) on tip body

**States:**
- **Collapsed (default):** Only trigger row visible. Tip body hidden.
- **Expanded:** Tip body slides open (no animation — instant show/hide for SSR compatibility).
- **Focus-visible:** 2px outline on trigger button.

### 3. Annotation Count Badge

Small badge on annotated elements indicating the number of annotations.

**Visual specs:**
- Displayed inline after the ingredient/step text when annotations exist
- Text: annotation count as digit, `text-sm`, `font-bold`
- Background: `var(--theme-badge-bg)` / color: `var(--theme-badge-text)` (reuses pack badge pattern)
- Size: min 20px × 20px circle, `border-radius: 50%`, centered text
- Placed after element text with 8px left margin

### 4. Variant Cross-Link

Displayed at the bottom of a recipe page when variants exist. Also shown on variant pages linking back to the original.

**Structure:**
```
┌─────────────────────────────────────────────────┐
│ See Also                                         │
│ ┌───────────────────────┐ ┌───────────────────┐ │
│ │ 🍂 Gluten-Free        │ │ 🍂 Vegan          │ │
│ │ Pumpkin Doughnut      │ │ Pumpkin Doughnut  │ │
│ └───────────────────────┘ └───────────────────┘ │
└─────────────────────────────────────────────────┘
```

**Visual specs:**
- Section heading: "See Also", `text-xl`, `font-bold`, 32px top margin, 16px bottom margin
- Each variant: block link, `var(--theme-surface)` background, 16px padding, `var(--radius-lg)` border-radius
- Variant title: `text-lg`, `font-bold`, `var(--theme-accent)` color
- Pack badge: reuse existing badge component if variant has a pack
- Hover: background → `var(--theme-surface-hover)`
- Layout: stack vertically on mobile, 2-column grid on ≥640px (`gap: 16px`)
- On variant pages, show "Based on: [Original Recipe Name]" link at the top of the recipe, `text-sm`, `var(--theme-text-secondary)`

### 5. Annotation Selection Indicator

Visual cue that the user has active annotation selections (URL has `?ann=` params).

**Visual specs:**
- Sticky bar at the bottom of the recipe page (above Start Cooking button area), shown only when ≥1 annotation is toggled on
- Text: "{N} substitution(s) applied", `text-sm`, `font-bold`
- Background: `var(--theme-surface)`, 1px top border `var(--theme-border)`
- Contains "Share this version" link (copies current URL with `?ann=` params) and "Reset" button (clears all toggles)
- Share link: `var(--theme-accent)` color | Reset: `var(--theme-text-secondary)` color
- Padding: 8px 16px
- Hidden when no annotations are active
- `print:hidden`

## Interaction Contracts

### Toggle Substitution
1. User taps toggle switch on annotated ingredient/step
2. Toggle animates thumb position (150ms ease)
3. Original text gets `line-through` + muted color; substitution text appears
4. URL updates with `?ann=` param encoding the active annotation IDs (no page reload — `history.replaceState`)
5. Annotation selection indicator bar appears/updates count
6. SSR fallback: without JS, all annotations render collapsed (original text only). Toggle buttons are hidden via `<noscript>` CSS or progressive enhancement.

### Expand Tip
1. User taps tip trigger row
2. Tip body appears instantly (no animation)
3. `aria-expanded` toggles, chevron flips
4. Tips are informational only — no URL param persistence needed

### Share Annotated Version
1. User taps "Share this version" in the selection indicator bar
2. Current URL (including `?ann=` params) is copied to clipboard via `navigator.clipboard.writeText()`
3. Link text briefly changes to "Copied!" for 2 seconds, then reverts
4. Fallback: if clipboard API unavailable, select the URL text for manual copy

### Enter Cooking Mode with Annotations
1. User has annotations toggled on (URL has `?ann=` params)
2. User taps "Start Cooking" button
3. Cooking mode URL includes the same `?ann=` params
4. Cooking mode renders substituted text in place of originals for active substitutions
5. Tips are not shown in cooking mode (distraction-free)

### URL Param Encoding
- Format: `?ann=1,3,5` — comma-separated annotation IDs (1-indexed per recipe)
- Each annotation in the YAML gets a deterministic numeric ID based on position (component index + item index + annotation index)
- Empty `?ann=` or no param = no annotations active (vanilla recipe)

## Cooking Mode Integration

Annotations in cooking mode follow existing cook-mode visual patterns:

| Element | Spec |
|---------|------|
| Substituted step text | Same `cook-step-text` styling (24px, weight 400, `var(--cook-text)`) — no visual distinction from original. The substitution IS the step now. |
| Substituted ingredient in sidebar | If ingredients shown, uses substituted text at same styling as non-annotated ingredients |
| Tips | Not displayed in cooking mode — cooking mode is distraction-free |
| Section labels | Unchanged — `cook-section-label` (14px, 700, uppercase) |

## Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Toggle switch | `<button role="switch" aria-checked="true/false">` with visible label |
| Tip disclosure | `<button aria-expanded="true/false" aria-controls="tip-{id}">` |
| Min touch target | 44px × 44px on all interactive elements (toggles, tip triggers, nav buttons) |
| Focus management | Focus-visible outlines on all interactive elements (2px accent, 2px offset) |
| Screen reader | Substitution toggle announces "Substitution: {text}, by {contributor}" on state change via `aria-label` |
| Reduced motion | Toggle thumb transition respects `prefers-reduced-motion: reduce` (instant swap) |
| No-JS fallback | Annotations render as collapsed/original text. No toggles displayed without JS. Recipe remains fully readable. |
