**Content quality checks per recipe** (per D-06):
- Title length ≤ 100 characters (error if exceeded)
- At least one actual direction step (not just group headers — check that `directions` contains at least one plain string entry or sub-array with length > 1)
- At least one component group with ingredients (group array length > 1, meaning header + at least one ingredient)
- Background field, if present, should be ≤ 2000 characters (warning, not error)

**Image presence check** (per D-06):
- For each recipe YAML file `data/recipes/foo_bar.yml`, check that `public/recipes/foo_bar.jpg` exists
- Use the base filename (without `.yml` extension) + `.jpg` to find the image — images use the SAME underscore naming as recipe files (NOT the hyphenated slug)
- Missing image = error (not warning)

**Output format:**
- Print each check result as it runs
- Collect all errors and warnings
- At the end: print summary and exit with code 1 if any errors, 0 if only warnings or clean
