**3. Create `app/controllers/packs/show.tsx`** — individual pack page:

Export `packShow(request: Request): Response` function.

Extract slug from URL: `url.pathname.split('/').pop()`.

Load pack via `loadPack(slug)`. Load recipes via `loadRecipesByPack(slug)`.

**Pack not found:** Return 404 with message per copywriting contract:
"Pack not found — this collection doesn't exist. Browse all packs or head home."
Include links to `/packs` and `/`.

**Pack found — render with full theme immersion:** Call `render(pack.name, content, { themeClass: pack.theme_class })` — overrides site-wide theme with this pack's theme.

**Header section:**
- Pack icon: 48px
- h1: pack name — Display (36px bold), `font-family:var(--theme-heading-font)`, `color:var(--theme-text)`
- p: pack description — 16px, `leading-relaxed`, `color:var(--theme-text-secondary)`, max-width 640px
- Separator: 1px `var(--theme-divider)`, full content width, 32px vertical margin

**Recipe cards (if recipes exist):**
Each card is a full `<a>` link to `/recipes/${slug}`:
- Background: `var(--theme-surface)`, border: `1px solid var(--theme-border)`, 8px border-radius, 16px padding
- Layout: flex row — content left, badge right
- Recipe title: 24px bold, `font-family:var(--theme-heading-font)`, accent color on hover
- Byline + location: 14px bold, `color:var(--theme-text-secondary)`
- CTA text: "Start Cooking →" — 16px bold, accent color, displayed below byline
- Pack badge: pack icon emoji in a 24px circle with `var(--theme-badge-bg)` background, positioned top-right
- Card hover: background → `var(--theme-surface-hover)`
- Card gap: 16px vertical between cards
- Container: single column, `max-w-2xl`

**Empty state (no recipes):**
- h2: "Recipes coming soon"
- p: "This collection is being curated. Recipes will appear here shortly."

Import `escapeHtml` locally (same pattern as show.tsx). Import `getRecipeSlug` from recipes.ts to derive slugs. Import `loadRecipesByPack` and `loadPack` from packs.ts. Also need recipe slugs — `listRecipeSlugs` and cross-reference.
