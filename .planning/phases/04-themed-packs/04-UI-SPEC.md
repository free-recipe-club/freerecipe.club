# Phase 4 — UI Design Contract

> Visual and interaction contract for Themed Packs. Generated by gsd-ui-researcher.
> This phase replaces the hardcoded green/cream brand with a CSS custom property theme system. The "Autumn Harvest" pack is the reference implementation.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none — server-rendered HTML with Tailwind v4 utility classes + CSS custom properties |
| Icon library | none — pack badge uses emoji/unicode characters (🍂 for Autumn Harvest) |
| Font | System sans-serif (body) + Georgia serif stack (headings, per-pack override via custom property) |

## CSS Custom Property Surface Area

This is the core design contract. Every theme pack overrides these properties via a body class (e.g., `theme-autumn-harvest`). Components consume `var(--theme-*)` tokens exclusively — no hardcoded color values in templates.

### Site-Wide Theme Properties

| Property | Purpose | Autumn Harvest Value |
|----------|---------|---------------------|
| `--theme-bg` | Page background (dominant) | `#faf5eb` |
| `--theme-bg-muted` | Muted background variant (sections, footer) | `#f0e6d3` |
| `--theme-surface` | Card/elevated surfaces | `#fff8f0` |
| `--theme-surface-hover` | Card hover state | `#f5ece0` |
| `--theme-text` | Primary text | `#292017` |
| `--theme-text-secondary` | Secondary/muted text | `#6b5c4d` |
| `--theme-accent` | Accent color (links, CTAs, brand elements) | `#c2410c` |
| `--theme-accent-hover` | Accent hover state | `#9a3412` |
| `--theme-accent-text` | Text on accent backgrounds | `#ffffff` |
| `--theme-border` | Borders, card outlines | `#ddd0be` |
| `--theme-divider` | List dividers, separators | `#e8dcc8` |
| `--theme-heading-font` | Heading font family | `Georgia, "Times New Roman", serif` |
| `--theme-body-font` | Body font family | `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif` |
| `--theme-badge-bg` | Pack badge background | `#c2410c` |
| `--theme-badge-text` | Pack badge text color | `#ffffff` |
| `--theme-badge-icon` | Pack badge character | `🍂` |
| `--theme-nav-bg` | Nav bar background (subtle tint) | `#f5ece0` |

### Cooking Mode Theme Properties

These replace the hardcoded `.cook-mode` values. The active theme class sets these; cooking mode CSS consumes them.

| Property | Purpose | Autumn Harvest Light | Autumn Harvest Dark |
|----------|---------|---------------------|---------------------|
| `--cook-bg` | Cooking mode background | `#faf5eb` | `#1c1917` |
| `--cook-surface` | Ingredient panel, progress track | `#f0e6d3` | `#292524` |
| `--cook-text` | Step text, ingredient text | `#292017` | `#fafaf9` |
| `--cook-text-secondary` | Step counter, exit button | `#6b5c4d` | `#a8a29e` |
| `--cook-accent` | Progress bar fill | `#c2410c` | `#fb923c` |
| `--cook-btn-bg` | Nav button backgrounds | `#c2410c` | `#fb923c` |
| `--cook-btn-text` | Nav button labels | `#ffffff` | `#1c1917` |

### Implementation Pattern

```css
/* Base theme properties — consumed by all templates */
body {
  background: var(--theme-bg);
  color: var(--theme-text);
  font-family: var(--theme-body-font);
}

/* Autumn Harvest theme */
.theme-autumn-harvest {
  --theme-bg: #faf5eb;
  --theme-bg-muted: #f0e6d3;
  --theme-surface: #fff8f0;
  --theme-surface-hover: #f5ece0;
  --theme-text: #292017;
  --theme-text-secondary: #6b5c4d;
  --theme-accent: #c2410c;
  --theme-accent-hover: #9a3412;
  --theme-accent-text: #ffffff;
  --theme-border: #ddd0be;
  --theme-divider: #e8dcc8;
  --theme-heading-font: Georgia, "Times New Roman", serif;
  --theme-body-font: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
  --theme-badge-bg: #c2410c;
  --theme-badge-text: #ffffff;
  --theme-badge-icon: "🍂";
  --theme-nav-bg: #f5ece0;

  /* Cooking mode inherits theme */
  --cook-bg: #faf5eb;
  --cook-surface: #f0e6d3;
  --cook-text: #292017;
  --cook-text-secondary: #6b5c4d;
  --cook-accent: #c2410c;
  --cook-btn-bg: #c2410c;
  --cook-btn-text: #ffffff;
}

@media (prefers-color-scheme: dark) {
  .theme-autumn-harvest .cook-mode {
    --cook-bg: #1c1917;
    --cook-surface: #292524;
    --cook-text: #fafaf9;
    --cook-text-secondary: #a8a29e;
    --cook-accent: #fb923c;
    --cook-btn-bg: #fb923c;
    --cook-btn-text: #1c1917;
  }
}
```

## Layout Contract

### Render Function Changes

The `render()` function in `app/controllers/render.tsx` replaces hardcoded `bg-brand-cream text-gray-900` with theme-aware classes:

```html
<body class="theme-autumn-harvest min-h-screen"
      style="background:var(--theme-bg);color:var(--theme-text);font-family:var(--theme-body-font)">
```

The theme class name is determined by the active pack config. The `render()` function reads the active pack and applies the corresponding class. Inline style ensures theme properties apply even before Tailwind utilities load.

### Theme Picker

A small dropdown toggled by clicking a palette icon (🎨) in the nav. Persists selection to `localStorage` key `frc-theme`.

**Closed state:** Single icon button (🎨) with `aria-label="Choose theme"`. 44px tap target. Positioned at right end of nav bar.

**Open state:** Dropdown panel below the nav, right-aligned. Contains one row per available pack:

| Element | Style |
|---------|-------|
| Pack option row | 44px height, 16px horizontal padding, flex row |
| Pack color swatch | 24px × 24px circle showing pack's accent color |
| Pack name | 14px bold, `var(--theme-text)` |
| Active indicator | 2px left border in accent color on the currently active pack |
| Container | `var(--theme-surface)` background, `var(--theme-border)` border, 8px border-radius |

**Behavior:**
1. Clicking a pack option applies that theme immediately (swaps body class)
2. Selection stored in `localStorage` under key `frc-theme` (value: theme class name, e.g., `theme-autumn-harvest`)
3. On page load, client JS reads `frc-theme` from localStorage and applies the class before first paint (inline `<script>` in `<head>`)
4. If no localStorage value, server-rendered default theme class applies
5. Clicking outside the dropdown closes it
6. Keyboard: `Escape` closes dropdown, arrow keys navigate options, `Enter` selects

**Client JS file:** `public/theme.js` — third client JS file in the project (after `cook.js`). Handles:
- Theme application from localStorage on load (blocking script in `<head>`)
- Theme picker toggle, selection, and persistence
- Dropdown open/close

## Pack Data Model

### Pack YAML Schema (`data/packs/<slug>.yml`)

```yaml
name: "Autumn Harvest"
slug: "autumn-harvest"
description: "Warm spices, golden leaves, and cozy kitchen moments. A collection of recipes for fall evenings."
icon: "🍂"
theme_class: "theme-autumn-harvest"
colors:
  bg: "#faf5eb"
  bg_muted: "#f0e6d3"
  surface: "#fff8f0"
  accent: "#c2410c"
  accent_hover: "#9a3412"
  text: "#292017"
  text_secondary: "#6b5c4d"
  border: "#ddd0be"
typography:
  heading_font: 'Georgia, "Times New Roman", serif'
  body_font: 'system-ui, -apple-system, "Segoe UI", Roboto, sans-serif'
```

### Recipe YAML Addition

```yaml
# Added to recipe-schema.ts as optional field
pack: "autumn-harvest"  # Optional. Pack slug. At most one per recipe.
```

### Active Pack Config

A `data/packs/_active.yml` file (or a field in a site config) declares the currently active pack:

```yaml
active: "autumn-harvest"
```

## Interaction States

### Theme Picker
| State | Behavior |
|-------|----------|
| Default (closed) | 🎨 icon button visible in nav |
| Hover | Icon opacity increases to 1 (from 0.7) |
| Open | Dropdown panel appears below nav, right-aligned |
| Option hover | Row background → `var(--theme-surface-hover)` |
| Option active | 2px left accent border, bold weight on name |
| Transition | Theme swap applies instantly — no animation on page elements, body class changes |

### Pack Cards (Index)
| State | Behavior |
|-------|----------|
| Default | Card with surface background, border, color stripe |
| Hover | Background → `var(--theme-surface-hover)`, box-shadow: `0 2px 8px rgba(0,0,0,0.08)` |
| Focus-visible | 2px accent outline, 2px offset |
| Active/pressed | No additional state |

### Recipe Cards (Pack Page)
| State | Behavior |
|-------|----------|
| Default | Card with surface background, border |
| Hover | Background → `var(--theme-surface-hover)`, title color → accent |
| Focus-visible | 2px accent outline, 2px offset |

### Theme Application on Load
| Scenario | Behavior |
|----------|----------|
| First visit, no localStorage | Server-rendered active pack theme applies |
| Return visit, localStorage set | Blocking `<script>` in `<head>` reads `frc-theme` and sets body class before paint |
| Pack page visit | Pack's own theme class applied regardless of site-wide active or localStorage |
| Cooking mode from themed recipe | `.cook-mode` inherits themed cooking variables |

## Accessibility

- All pack cards are full `<a>` elements with descriptive link text (pack name)
- Theme picker button has `aria-label="Choose theme"`
- Theme picker dropdown has `role="listbox"`, options have `role="option"`, active has `aria-selected="true"`
- Pack badge emoji has `aria-hidden="true"` with a visually hidden text label for screen readers
- Color contrast meets WCAG AA for all text/background pairs (verified in Color section)
- Focus-visible outlines on all interactive elements (2px accent, 2px offset)
- Theme picker keyboard navigation: `Escape` to close, `ArrowUp`/`ArrowDown` to navigate, `Enter` to select

---

## Print Behavior

Pack themes do not affect print styles. The existing `@media print` block in `input.css` continues to override to white background / black text. Pack badges are hidden in print via `print:hidden`.
