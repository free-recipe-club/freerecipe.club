**2. Create `app/controllers/recipes/show.tsx`:**

Export a `recipeShow(request: Request): Response` function following the established controller pattern.

**Slug extraction:** Parse `request.url`, extract the last pathname segment as the slug. Convert to filename via `getRecipeFilename(slug)`. Pass filename to `loadRecipe()`.

**Error handling:** Wrap `loadRecipe()` in try/catch. On error (recipe not found), return `render('Recipe not found', ...)` as a 404 Response. The 404 page body per UI-SPEC Copywriting Contract:
- Heading: "Recipe not found"
- Body: "We couldn't find that recipe. Browse <a href="/recipes">all recipes</a> to find something to cook."

**Recipe HTML layout — all within a `<main class="max-w-2xl mx-auto px-4 py-8">`:**

Section 1 — Compact header (per D-01, UI-SPEC):
```html
<header class="flex items-start gap-4 mb-8">
  <img src="/recipes/{slug}.jpg" alt="{recipe.title}" width="80" height="80"
       class="w-20 h-20 rounded object-cover flex-shrink-0 recipe-image">
  <div>
    <h1 class="text-3xl font-bold text-brand-green">{recipe.title}</h1>
    <p class="text-sm text-gray-600">{recipe.byline}, {recipe.location}</p>
  </div>
</header>
```
If image doesn't exist, the `<img>` will 404 silently — the CSS handles this gracefully since header uses flex layout and title takes full width.

Section 2 — Ingredients (per D-02, D-03, UI-SPEC):
```html
<section class="mb-8">
  <h2 class="text-xl font-bold mb-4">Ingredients</h2>
  {for each component group in recipe.components:}
  <div class="mb-6">
    <h3 class="text-xl font-bold mb-2">{group[0]}</h3>
    <ul class="space-y-2">
      {for each ingredient in group.slice(1):}
      <li class="text-lg leading-relaxed">{ingredient}</li>
    </ul>
  </div>
</section>
```

Section 3 — Directions with checkboxes (per D-07, D-08, D-09, UI-SPEC Interaction Contract):
```html
<section class="mb-8">
  <h2 class="text-xl font-bold mb-4">Directions</h2>
  <ol class="list-decimal list-inside space-y-3">
    {for each step in recipe.directions:}
    <li class="text-lg leading-relaxed">
      <label class="cursor-pointer">
        <input type="checkbox" class="peer sr-only">
        <span class="peer-checked:line-through peer-checked:text-gray-400">{step}</span>
      </label>
    </li>
  </ol>
</section>
```

CSS-only checkboxes using Tailwind `peer`/`peer-checked:` — no JavaScript. Ephemeral (resets on page reload per D-07). `sr-only` hides the checkbox visually but keeps it accessible. Full step text is the tap/click target via `<label>`.

Section 4 — Flavor & Background muted section (per D-03, UI-SPEC):
Only render this section if `recipe.flavor` or `recipe.background` has content:
```html
<section class="bg-brand-cream-muted rounded p-6 mb-8 recipe-background">
  {if recipe.flavor:}
  <p class="text-lg leading-relaxed text-gray-600 mb-4">{recipe.flavor}</p>
  {if recipe.background:}
  <p class="text-lg leading-relaxed text-gray-600">{recipe.background}</p>
</section>
```

Section 5 — Attribution (per D-04, UI-SPEC):
```html
<footer class="text-sm text-gray-600">
  {recipe.links as comma-separated list:}
  <a href="{link.url}" target="_blank" rel="noopener noreferrer" class="text-brand-green hover:underline">{link.text}</a>
</footer>
```
