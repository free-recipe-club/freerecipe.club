## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline gaps (e.g., space between checkbox and step text) |
| sm | 8px | Tight element spacing (between byline and location, list item padding) |
| md | 16px | Default element spacing (paragraph gaps, ingredient item spacing, page horizontal padding on mobile) |
| lg | 24px | Section gaps (between ingredient groups, between sections on detail page) |
| xl | 32px | Major section breaks (above/below directions, above muted footer) |
| 2xl | 48px | Page vertical padding (top/bottom of content area) |
| 3xl | 64px | Not used in this phase |

Exceptions: Checkbox tap area — the `<label>` wrapping each step provides a full-width tap target. Minimum effective tap height is 44px (achieved via line-height + padding on each step `<li>`).

## Typography

| Role | Size | Weight | Line Height | Tailwind Class |
|------|------|--------|-------------|----------------|
| Meta | 14px | 400 | 1.5 | `text-sm` |
| Body | 18px | 400 | 1.6 | `text-lg leading-relaxed` |
| Subheading | 20px | 700 | 1.3 | `text-xl font-bold` |
| Heading | 30px | 700 | 1.2 | `text-3xl font-bold` |

**Scale rationale:** 18px body (not 16px) is a deliberate kitchen-readability choice per DISP-07. Steps and ingredients must be readable at arm's length on a phone propped on a counter.

**Usage by context:**

| Context | Role Applied |
|---------|-------------|
| Recipe title (h1) | Heading (30px bold) |
| Section headers ("Ingredients", "Directions") | Subheading (20px bold) |
| Ingredient group name (e.g., "Doughnuts", "Topping") | Subheading (20px bold) |
| Ingredient items, direction steps | Body (18px regular) |
| Byline, location, attribution links | Meta (14px regular) |
| Flavor text, background text | Body (18px regular) in secondary text color |
| Listing page recipe title (link) | Subheading (20px bold) |
| Listing page byline + flavor | Meta (14px regular) |

## Layout Contract

### Navigation Bar

Minimal text nav on every page. Single row, vertically centered.

| Element | Content | Style |
|---------|---------|-------|
| Left | `freerecipe.club` | Subheading (20px bold), brand-green, links to `/` |
| Right | `Recipes` | Body (18px), brand-green, links to `/recipes` |
| Container | `max-w-2xl mx-auto px-4 py-3` | Consistent with content width |
| Print | Hidden | `print:hidden` |

### Recipe Detail Page (`/recipes/:slug`)

Single-column layout. Content width: `max-w-2xl` (672px). Horizontal padding: 16px mobile.

**Section order (top to bottom):**

1. **Compact header** — Thumbnail (80×80px, rounded, `object-cover`) floated/flexed left of title block. Title block: recipe title (Heading), byline + location (Meta, secondary text color). If no image exists, header renders without thumbnail — title takes full width.
2. **Ingredients** — Section heading "Ingredients" (Subheading). Each component group: group name as Subheading (e.g., "Doughnuts"), followed by an unordered list of ingredients in Body size. Groups separated by 24px gap.
3. **Directions** — Section heading "Directions" (Subheading). Ordered list (`<ol>`). Each step is a `<li>` containing a `<label>` wrapping a visually-hidden checkbox (`sr-only`) and step text. Step numbers rendered by CSS `list-style: decimal`. Minimum 44px effective tap height per step.
4. **Flavor & Background** (muted section) — Full-width band of `brand-cream-muted` background. Flavor text first (Body, secondary text color), then background text (Body, secondary text color). Section only renders if either field has content.
5. **Attribution** — Links rendered as a comma-separated list in Meta size, secondary text color. Link text as-is from data; external links get `rel="noopener noreferrer"` and `target="_blank"`.

**Page `<title>`:** `{Recipe Title} — freerecipe.club`
**Meta description:** `<meta name="description" content="{flavor}">` — omit tag if flavor is empty.

### Recipe Listing Page (`/recipes`)

Single-column layout. Same `max-w-2xl` container.

**Page heading:** "Recipes" (Heading, 30px bold).

**Recipe list:** Not a card grid — a simple vertical text list (per D-05). Each item:

| Element | Style |
|---------|-------|
| Recipe title | Subheading (20px bold), brand-green, links to `/recipes/{slug}` |
| Supporting line | `{byline}, {location}` in Meta (14px), secondary text color |
| Flavor text | Meta (14px), secondary text color, below supporting line |
| Separator | 1px `brand-cream-muted` border-bottom between items |
| Item padding | 16px vertical (py-4) — yields 44px+ tap target with text height |

**Page `<title>`:** `Recipes — freerecipe.club`

**Empty state:** Rendered when `loadRecipes()` returns zero results. See Copywriting Contract.

### Sitemap (`/sitemap.xml`)

No visual component. XML response with `Content-Type: application/xml; charset=utf-8`. Lists all recipe URLs plus `/` and `/recipes`. No UI contract needed.

## Interaction Contract

### Step Checkboxes (DISP-04)

| Property | Value |
|----------|-------|
| Element | `<input type="checkbox">` inside `<label>` wrapping step text |
| Visibility | Checkbox visually hidden (`sr-only`), entire step text is the click/tap target |
| Checked state | Step text gets `line-through` + `text-gray-400` via `peer-checked:` |
| Persistence | Ephemeral — no localStorage, no cookies, resets on page reload (D-07) |
| Accessibility | `<label>` wrapping provides click target; screen readers announce checkbox state |
| CSS mechanism | Tailwind `peer`/`peer-checked:` variant — zero JavaScript |
| Tap target | Full step text width × line-height + padding ≥ 44px effective height |

### Navigation Links

| Property | Value |
|----------|-------|
| Hover state | `underline` decoration |
| Active page | No special indicator needed (only 2 nav items, context is clear from page content) |

### Listing Page Recipe Links

| Property | Value |
|----------|-------|
| Hover state | `underline` decoration on title |
| Tap target | Full-width list item row (block-level `<a>` or link covers title + meta) |

## Print Contract (DISP-06)

Per D-10: print output is text-focused, chrome-free.

**Included in print:**
- Recipe title
- Ingredients (all groups)
- Directions (steps as numbered list, no checkboxes)
- Flavor text
- Attribution (links rendered as text with URL in parentheses)

**Excluded from print:**
- Navigation bar
- Recipe image/thumbnail
- Background story section
- Checkboxes (`input[type="checkbox"]`)
- Any interactive elements

**Print CSS rules (add to `input.css`):**

| Rule | Effect |
|------|--------|
| `nav { display: none }` | Hide navigation |
| `.recipe-image { display: none }` | Hide thumbnail |
| `.recipe-background { display: none }` | Hide background story |
| `input[type="checkbox"] { display: none }` | Hide checkboxes |
| `body { background: white; color: black }` | Reset for printing |
| `a { color: black; text-decoration: none }` | Flatten links |
| `a[href]::after { content: " (" attr(href) ")"; font-size: 0.8em }` | Reveal URLs |

**Implementation approach:** Mix of Tailwind `print:hidden` on individual elements and `@media print` block in `input.css` for global resets.

## Responsive Contract (DISP-07, CORE-03)

Mobile-first approach. All base styles target phones (320px+).

| Breakpoint | Width | Adjustments |
|------------|-------|-------------|
| Base (mobile) | 320px+ | Full-width content, 16px horizontal padding, 18px body text |
| `sm:` | 640px+ | No changes needed — single column scales naturally |
| `md:` | 768px+ | Increased horizontal padding (24px) if desired |
| `lg:` | 1024px+ | Content constrained to `max-w-2xl` (672px), centered |

**Key mobile constraints:**
- All tap targets ≥ 44px effective height
- No horizontal scroll at 320px viewport
- Recipe content readable without zooming (18px body)
- Single column throughout — no sidebar, no multi-column layout (D-02)
