# Requirements Archive: v1.0 MVP

**Archived:** 2026-03-24
**Core Value:** Someone finds a recipe and actually cooks from it.

## v1 Requirements — Final Status

### Scaffolding

- [x] **SCAF-01**: Project scaffolded with alpha Remix framework (remix-run/remix)
- [x] **SCAF-02**: Tailwind v4 configured with CSS-first approach
- [x] **SCAF-03**: GitHub Actions CI/CD pipeline for build and deployment
- [x] **SCAF-04**: Hosting solution determined (static build, DigitalOcean)

### Recipe Display

- [x] **DISP-01**: Clean, recipe-first layout — title, image, ingredients, steps, attribution. No preamble.
- [x] **DISP-02**: Recipe images displayed with alt text
- [x] **DISP-03**: Grouped ingredient lists by component (e.g., "Doughnuts", "Topping")
- [x] **DISP-04**: Numbered steps with checkable progress
- [x] **DISP-05**: Attribution and source links displayed prominently
- [x] **DISP-06**: Print-friendly CSS (@media print strips navigation chrome)
- [x] **DISP-07**: Mobile-responsive, kitchen-first design (phone-friendly, large tap targets)
- [x] **DISP-08**: Recipes render fully via SSR — JavaScript enhances but isn't required to read
- [x] **DISP-09**: Full cooking mode — screen wake lock, large text, step-by-step navigation, large tap targets for wet hands
- [x] **DISP-10**: Ingredient highlighting per active step in cooking mode

### Data

- [x] **DATA-01**: Zod schema validation for recipe YAML files at the build/load boundary
- [x] **DATA-02**: YAML remains the recipe data format (human-readable, PR-friendly)

### SEO & Discovery

- [x] **SEO-01**: Clean URLs for recipes (/recipes/pumpkin-doughnut)
- [x] **SEO-02**: XML sitemap auto-generated from recipe list

### Community & Contributions

- [x] **COMM-01**: Recipe PR template (YAML scaffold for contributors)
- [x] **COMM-02**: CI validation of recipe format on pull requests
- [x] **COMM-03**: Hacktoberfest-ready repo (good-first-issue labels, contributor guide, welcoming README, CODE_OF_CONDUCT)
- [x] **COMM-04**: Community annotations — inline substitutions, tips, and modifications pinned to specific recipe ingredients or steps
- [x] **COMM-05**: Recipe versioning — significant annotation sets can graduate to standalone recipe variants (forks)
- [x] **COMM-06**: Non-technical contribution path documented (email/letter → maintainer creates GitHub issue → recipe added via PR)

### Themed Packs

- [x] **PACK-01**: First themed recipe pack curated and included at launch
- [x] **PACK-02**: CSS theme system using custom properties (switchable per pack)
- [x] **PACK-03**: Pack landing page displaying curated recipe collection

### Core Principles

- [x] **CORE-01**: Zero ads, zero tracking, zero third-party scripts, zero dark patterns
- [x] **CORE-02**: No accounts required — readers are anonymous, contributors use GitHub identity
- [x] **CORE-03**: Multi-device responsive design (phones, tablets, desktops — kitchen-first)
